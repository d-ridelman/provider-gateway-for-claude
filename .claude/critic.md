Это Provider Gateway for Claude (PGC): Rust и Tauri 2 под Windows, шлюз Anthropic Messages к сторонним моделям.

Правила проекта — `AGENTS.md` и `.claude/rules/` (`gateway.md` для шлюза, `ui.md` для окна), решения — `docs/adr/`.
Изменение, которое затрагивает больше одного модуля или контракт, идёт с ADR.

Что проверять особо:
- исправление ошибки идёт с тестом, который падает без исправления;
- текст для человека — на двух языках: `tr!("ru", "en")` в Rust, `crates/ctp-app/ui/i18n.js` в окне;
- шлюз отвечает клиенту только в форме Anthropic: ошибки, порядок событий SSE, «prompt is too long» при переполнении,
  оборванный провайдером поток — событие `error`, а не `end_turn`;
- новое поведение шлюза идёт с интеграционным тестом в `crates/ctp-gateway/tests/gateway.rs` на заглушке `wiremock`;
- окно — только общая шкала `styles.css` (радиусы, размеры, без новых теней и цветов), строки в `i18n.js` на ru и en;
- ключ провайдера не попадает ни в ответ, ни в журнал;
- репозиторий публичный: в коде и документах нет личных путей, заметок владельца и снятого из декомпилята Claude;
- изменение для человека отмечено в `CHANGELOG.md`.
