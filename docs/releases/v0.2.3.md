- **The effort menu of the Russian Claude is in Russian**: levels, their description and the thinking modes from the model catalog had no translation in claude.ai's `ru.json`; the copy adds them (it is rebuilt once after the update). The translation keeps up with Claude updates: PGC also downloads claude.ai's `dynamic/ru.json` and builds the menu file for the strings of the installed Claude version, filling gaps from its own dictionary and from matching strings of the main translation. The settings check shows how many menu strings are translated.

Checked live: Opus 5.5 with an Anthropic API key answers in the Code tab of Claude Desktop and loads MCP tools through tool search.
