Claude Code works with an Anthropic API key, and a new page connects agent-kit to a project.

### Fixed

- **Claude Code with an Anthropic API key, in the Code tab of Claude Desktop and in the console.** Anthropic answers an API key "Your credit balance is too low" whatever the balance when a request is labelled as interactive Claude Code: in the `user-agent` (`claude-cli/… (external, cli)`, the Code tab's `claude-desktop-3p`) and in Claude Code's attribution block at the top of the system prompt (`cc_entrypoint=…`). Every message failed with "Billing problem". The gateway now introduces Claude Code to Anthropic-compatible providers as `claude -p` does (`sdk-cli`) in both places; SDK labels and other clients are left as they are.

- **The effort menu of the Russian Claude is in Russian**: levels, their description and the thinking modes from the model catalog had no translation in claude.ai's `ru.json`; the copy adds them (it is rebuilt once after the update). The translation keeps up with Claude updates: PGC also downloads claude.ai's `dynamic/ru.json` and builds the menu file for the strings of the installed Claude version, filling gaps from its own dictionary and from matching strings of the main translation. The settings check shows how many menu strings are translated.

- **A gateway model no longer stays in Claude Code's own settings.** `/model` in a PGC console saved the chosen model as the default of every Claude Code, so a plain `claude` without PGC opened on a model it cannot reach. PGC now puts the user's own model back when it exits and on the next start.

- **One row per 1M model in Claude's model menu.** A model marked `[1m]` no longer appears twice ("…" and "… 1M" with an English note). Claude models from Anthropic too: Claude 5.x has a native 1M window, so both rows were the same model with the same window.

### Added

- **Connect a project.** A sidebar page turns agent-kit (checks, a critic and secret guarding for agents) on in a project without typing commands. "Check" changes nothing and says what is missing; "Connect" enables it only for you unless you tick "for the whole team". Then it shows what the project has and a plan with ticks; only ticked items are applied, and existing files are never overwritten.

- **Project checks with ticks.** The page lists the checks the project already writes down (package.json, Cargo, Makefile, pyproject, Go, its CI), each with its file and line. Likely checks are ticked; commands whose name says they change or ship something are unticked, with the reason. The ticked ones become the steps of a new `.claude/verify.json`; a project's own one is left alone, and the steps are shown to add by hand. Nothing is run, and no file leaves the computer.

- **agent-kit comes inside PGC.** The installer carries a pinned agent-kit, so connecting a project needs no other download; a newer PGC offers "Update agent-kit" on the page, nothing updates by itself. agent-kit needs Node.js 22 or newer.

- **A critic model for project scripts.** In the settings you can pick another model that reviews an agent's work. Claude and the console opened from PGC pass it to project scripts, so a reviewer works without a Claude subscription too.

Checked live: Opus 5.5 with an Anthropic API key answers in the Code tab of Claude Desktop and loads MCP tools through tool search.

Claude Code работает с ключом Anthropic API, а новая страница подключает agent-kit к проекту.

### Исправлено

- **Claude Code с ключом Anthropic API — во вкладке Code у Claude Desktop и в консоли.** Anthropic отвечает ключу API «Your credit balance is too low» при любом балансе, если запрос помечен как интерактивный Claude Code: в `user-agent` (`claude-cli/… (external, cli)`, у вкладки Code — `claude-desktop-3p`) и в блоке атрибуции Claude Code в начале системного промпта (`cc_entrypoint=…`). Каждое сообщение падало с «Проблемой с оплатой». Теперь шлюз представляет Claude Code Anthropic-совместимым провайдерам так же, как `claude -p` (`sdk-cli`), в обоих местах; метки SDK и другие программы не трогаются.

- **Меню уровня усилий в русском Claude — по-русски**: уровни, их описание и режимы размышлений из каталога моделей не имели перевода в `ru.json` claude.ai; копия дописывает их (после обновления она один раз пересоберётся). Перевод успевает за обновлениями Claude: PGC скачивает и `dynamic/ru.json` claude.ai и собирает файл меню под строки установленной версии Claude, а пробелы закрывает своим словарём и совпадающими строками основного перевода. Самопроверка в настройках показывает, сколько строк меню переведено.

- **Модель шлюза больше не остаётся в настройках Claude Code.** `/model` в консоли PGC сохранял выбранную модель моделью по умолчанию для всех Claude Code, и обычный `claude` без PGC открывался на модели, до которой ему не достучаться. Теперь PGC при выходе и при следующем запуске возвращает прежнюю модель человека.

- **Одна строка в меню моделей Claude на модель с окном 1M.** Модель с `[1m]` больше не показывается дважды («…» и «… 1 млн» с английской подписью). У моделей Claude от Anthropic тоже: у Claude 5.x окно 1M своё, и обе строки были одной моделью с одним окном.

### Добавлено

- **Подключить проект.** Страница в боковой панели включает agent-kit (проверки, критик и охрана секретов для агентов) в проекте без ручных команд. «Проверить» ничего не меняет и говорит, чего не хватает; «Подключить» включает его только у вас, если не отмечено «для всей команды». Потом страница показывает, что есть в проекте, и план с галочками; применяется только отмеченное, существующие файлы не перезаписываются.

- **Проверки проекта с галочками.** Страница показывает проверки, которые проект уже записал у себя (package.json, Cargo, Makefile, pyproject, Go, его CI), у каждой — файл и строка. Похожие на проверки отмечены; команды, имя которых говорит, что они что-то меняют или выпускают, — без галочки и с причиной. Отмеченные становятся шагами нового `.claude/verify.json`; свой файл проекта не трогается, шаги показываются, чтобы добавить их вручную. Ничего не запускается, и ни один файл не уходит с компьютера.

- **agent-kit приезжает внутри PGC.** В установщике есть закреплённая версия agent-kit, так что для подключения больше ничего качать не нужно; более новый PGC предлагает «Обновить agent-kit» на странице, сам ничего не обновляет. agent-kit нужен Node.js 22 или новее.

- **Модель-критик для скриптов проекта.** В настройках можно выбрать другую модель, которая проверяет работу агента. Claude и консоль из PGC передают её скриптам проекта, так что проверка работает и без подписки Claude.

Проверено вживую: Opus 5.5 с ключом Anthropic отвечает во вкладке Code у Claude Desktop и подгружает инструменты MCP через поиск.
