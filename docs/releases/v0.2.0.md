Different gateway models for Claude Code's roles and subagents.

### New

- **Models for Claude Code** (Settings). Claude Code asks for models by role: `sonnet`, `opus`, `haiku`. Now each role can run on its own gateway model:
  - **main** (`sonnet`) — the console session, subagents that inherit the model (Explore, Plan) and every role left unassigned;
  - **strong** (`opus`) — subagents with `model: opus`;
  - **fast** (`haiku`) — subagents with `model: haiku` and background tasks.

  The choice applies to the Claude Code console, the copied command and the Code tab of Claude Desktop, from the next **Open Claude**. Nothing chosen means the old behaviour.
- **Copy the Claude Code command** now gives exactly what the Claude Code button sets, context window included.

### Fixed

- Code sessions in the Russian copy of Claude, with their shells and MCP servers, see the usual `%LOCALAPPDATA%`, like in the regular Claude.
- No more 400 "is not a regex" from providers when an MCP tool's schema uses a regex they cannot read.

The app updates itself from this page; or download the installer below.

Разные модели шлюза для ролей и субагентов Claude Code.

- **Модели для Claude Code** (Настройки). Claude Code просит модели по ролям: `sonnet`, `opus`, `haiku`. Теперь у каждой роли может быть своя модель шлюза:
  - **основная** (`sonnet`) — сессия в консоли, субагенты, которые наследуют модель (Explore, Plan), и все невыбранные роли;
  - **сильная** (`opus`) — субагенты с `model: opus`;
  - **быстрая** (`haiku`) — субагенты с `model: haiku` и фоновые мелочи.

  Выбор действует в консоли Claude Code, в скопированной команде и во вкладке Code у Claude Desktop — со следующего «Открыть Claude». Если ничего не выбрано, всё как раньше.
- **Скопировать команду для Claude Code** теперь даёт ровно то же, что задаёт кнопка Claude Code, вместе с окном контекста.
- Исправлено: сессии Code в русской копии Claude, их оболочки и MCP-серверы видят обычную папку `%LOCALAPPDATA%`, как в обычном Claude.
- Исправлено: провайдеры больше не отвечают 400 «is not a regex», если в схеме инструмента MCP есть регулярка, которую их движок не понимает.

Приложение обновится само с этой страницы, или скачайте установщик ниже.
