Cowork works in Claude Desktop on 3P, Claude opens on Chat, and the gateway updates and checks are safer.

### Added

- **Cowork in Claude Desktop on 3P, without an MSIX install.** The Russian copy carries small `app.asar` patches, so Cowork runs on the host on a portable copy, without administrator rights and without a VM. Its shell is Claude Code's PowerShell and Bash, not isolated, and every call asks for approval.
- **Cowork with the VM, through MSIX, as an option.** The new `Cowork` setting has three modes: on the host, off (Chat only), and through an installed Claude MSIX package with the VM. The VM mode starts the real Claude from the package with the standard `Claude-3p` profile; there is no Russian translation in that mode.
- **The translated copy can be built from the MSIX package.** Anthropic's installer now ships Claude as an MSIX package and removes the Squirrel folder; when there is no portable or Squirrel copy, PGC takes `claude.exe` from the installed package.
- **A conversation compaction window setting** that works for models marked `[1m]`, for Desktop and the console.
- **Artifacts (Design and Slides, beta)**, a tick in the settings.

### Changed

- **Claude opens on Chat, not in the Code tab.** A stored Code surface left from one click on Code is switched back to Chat; an explicit Chat choice is left alone.

### Fixed

- **A substituted Claude is rejected.** The Authenticode check compared only the certificate name, so a code-signing certificate from a corporate proxy's root (or a revoked one) passed for the downloaded Claude. Both files must now be issued by Anthropic's own code-signing CA; the revocation check runs when the network allows it and is skipped behind a proxy instead of blocking the update.
- **"Connect project" can no longer hang forever** when a grandchild process keeps the output pipe open after the command exits.
- **The project checks can no longer pass silently:** `ci.ps1`, `ui-shots.mjs` and the i18n check now fail on findings they used to print and ignore.
- **The VPN toggle no longer freezes the window** while the core stops; **"Update the installed Claude" no longer fails with 403**; **Cowork on the host no longer shows "prepare: no_vm"**.
- **Smaller fixes:** the "no key needed" hint accepts only a real loopback address; a language switch updates the Projects page; a deep project path no longer scrolls the card sideways; model aliases use the new rules from the first launch after a Claude update; the state line sees a Claude started in VM mode; a failing folder picker says why; clearing the Artifacts tick really turns artifacts off.

Checked live: the installed MSIX signature, the copy built from the real package, Cowork on the host in Windows Sandbox, and the VM mode on a machine with the MSIX (the service configures, the VM boots in about 14 seconds, a shell command runs inside the guest).

- Launching the copy built from the MSIX package.
