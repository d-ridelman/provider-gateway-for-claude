MCP tools on demand, a VPN on the mihomo core, free web search for Claude and a new window.

### New

- **MCP tools on demand.** Through a gateway, Claude Code used to send every MCP tool's schema on every turn: with a few connectors that was 500–600 tools and 150–180 thousand tokens before a word was said. Now Claude Code finds tools with its own tool search, as the regular Claude does: about 40 thousand input tokens on the first turn instead of about 220 thousand, in the console and in the Code tab of Claude Desktop.
- **Proxy and VPN on the mihomo core.** VPN subscriptions (Clash/mihomo links or base64 vless, vmess, ss, trojan, hysteria2), nodes with latency and Auto first. Modes: off; Claude and providers only; the Windows system proxy (your previous settings come back on exit); all traffic through TUN (Windows asks for administrator rights). The core (mihomo v1.19.34, GPL-3.0) is downloaded on request from its GitHub releases, sha256 checked.
- **Free web search for Claude's built-in `WebSearch`.** The gateway answers the search itself (Brave first, DuckDuckGo as fallback; cached for 10 minutes), no API keys needed.
- **Claude Desktop and Claude Code downloads** in Settings: portable or the official install, with sha256/sha1 and Anthropic's signature checked; with the VPN on, the downloads go through it.
- **A new window and icon:** one style, crisper text, light and dark theme and RU / EN in the app.

### Changed

- **One model for Claude Code.** Every role (`opus`, `haiku`, `fable`) goes to the main model, and the console shows it by its real name in the header and in `/model`. Code-tab sessions of Claude Desktop get the same Claude Code settings as the console (task tools, auto mode, tool search).
- **No more advisor** and no "Copy the Claude Code command": PGC no longer writes to Claude Code's shared `settings.json`. A leftover `advisorModel` (remove it with `/advisor off`) does not break a provider.
- **Steadier with picky models and long chats:** Anthropic's own error types and "prompt is too long", so Claude Code retries and compacts by itself; a bare 400 is retried in simplified form and the working step is remembered; screenshots are counted by pixel size; a cut stream is an error, not a finished answer.

Full list: [CHANGELOG](https://github.com/d-ridelman/provider-gateway-for-claude/blob/main/CHANGELOG.md).

### Not checked yet

- Claude Desktop with the English interface opened from PGC (the copy without translation was built from the real Claude, not run).
- The VPN modes on a real subscription (the system proxy and TUN were checked in Windows Sandbox only) and the core's restart after sleep.
- The official DeepSeek and Z.ai APIs, Kimi and MiniMax (DeepSeek and GLM were tried through other providers).
- Windows display scale 125–150 %: snapshots only.

The app updates itself from this page; or download the installer below. Checksums are in `SHA256SUMS.txt`. The installer is per-user (`/S` for a silent install); the portable exe needs no installation.

### Изменено

- **Одна модель для Claude Code.** Все роли (`opus`, `haiku`, `fable`) идут на основную модель, а консоль показывает её настоящее имя в заголовке и в `/model`. Сессии вкладки Code у Claude Desktop получают те же настройки Claude Code, что и консоль (задачи, автоматический режим, поиск инструментов).
