The first public release: run Claude Desktop and Claude Code on the models you choose.

### Highlights

- **Any OpenAI- or Anthropic-compatible provider**, with templates for OpenAI, OpenRouter, OpenCode Go and Zen, DeepSeek, Gemini, Anthropic, Ollama, llama.cpp and LM Studio.
- **Claude Desktop in a separate profile**: your Claude account and chats are not touched.
- **Claude Code in one click**: a console in your project folder, already connected to the gateway.
- **Load models from the provider**: names, 1M-context models and reasoning levels filled in from the OpenCode model catalog.
- **Survives Claude updates**: reads the model rules of the installed version and reports what no longer matches.
- **English and Russian interface**, picked from Windows; light and dark themes.
- **Russian Claude Desktop** (optional): a separate copy of Claude with claude.ai's Russian translation and **No folder** for Code sessions, which third-party mode hides.
- **Signed updates** from this page, checked against the key built into the app.

### Download

| File | What it is |
|---|---|
| `Provider-Gateway-for-Claude_0.1.0_x64-setup.exe` | Installer, current user only, no admin rights |
| `Provider-Gateway-for-Claude_0.1.0_x64-portable.exe` | Portable app, no installation |
| `SHA256SUMS.txt` | Checksums of both |
| `latest.json`, `.sig` | Used by the built-in updater |

The files are not code-signed yet, so SmartScreen may warn about an unknown publisher: **More info → Run anyway**.

Requires Windows 10 or 11 (x64) with WebView2. Tested with Claude Desktop 6.6395.0.
