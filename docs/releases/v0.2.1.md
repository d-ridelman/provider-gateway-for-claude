Claude Code's advisor, answered by your strong model.

### New

- **Advisor through the gateway.** Claude Code's advisor (`/advisor`) lets the working model consult a stronger one mid-task. At Anthropic it runs on their server, so through a third-party provider it was simply off. Now, with a **strong** model chosen in Settings → Models for Claude Code, the gateway runs it: the main model calls `advisor`, the gateway asks the strong model with the whole conversation and puts the advice into the same reply.
  - Turn it on once in Claude Code: `/advisor opus` (or `fable`).
  - Works with OpenAI-compatible providers, in the **Claude Code** console and in the Code tab of the Russian copy of Claude Desktop.
  - Not covered yet: the Code tab of the regular Claude Desktop and Anthropic-type providers.
- Subagents with `model: fable` use the strong model too (in the Russian copy of Claude Desktop — when the strong model is on an OpenAI-compatible provider).
