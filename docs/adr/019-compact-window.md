# ADR-019. Окно сжатия разговора: одна настройка PGC для Desktop и консоли

- Status: Accepted
- Date: 2026-11-26

## Context
Человек хочет сжимать разговор раньше, чем кончится окно модели (например, на 400K из 1M).
У Claude Code для этого три средства:
- `CLAUDE_CODE_AUTO_COMPACT_WINDOW` — токены (`400k`, минимум 100K), приоритетнее файлов настроек;
- `autoCompactWindow` в `modelSettings["<модель>"]` файла `settings.json`, его пишет `/autocompact`;
- `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` — процент, только вниз.

Проверено вживую на Claude Code 2.1.330 (stream-json, как у Desktop, заглушка вместо шлюза,
изолированный `CLAUDE_CONFIG_DIR`): для модели с `[1m]` в имени `/autocompact 400k` пишет
ключ без `[1m]` (`claude-opencode-78821968`), а читает ключ с ним
(`claude-opencode-78821968[1m]`). Записанное не применяется: следующий `/autocompact`
показывает `auto`, а сама команда отвечает «higher-priority override is active (1m tokens)».
Ключ с `[1m]` читается; без `[1m]` в имени модели работает обычный ключ.

Desktop запускает сессии Code моделями PGC как `<псевдоним>[1m]` (ADR-011, `prefer1m`), то
есть `/autocompact` в них не работает. Ключ Desktop для переменных и настроек сессии
(`claudeCodeSettings`) в 6.28899.6 помечен `@next` и недоступен.

## Decision
В настройках PGC (группа Claude Code) одно поле «Окно сжатия»: пусто — как решит Claude Code;
`400k`, `400000` или `40%`.
- Токены: от 100K (минимум Claude Code) до 1M. Процент — доля окна модели: для `[1m]` это 1M,
  для обычной строки 200K; результат тоже от 100K.
- **Консоль PGC**: `CLAUDE_CODE_AUTO_COMPACT_WINDOW` в `code_env` (процент считается от окна,
  которое PGC задаёт этой консоли). Переменная приоритетнее файла, ключ модели не важен.
- **Desktop**: PGC пишет `autoCompactWindow` в `modelSettings` общего `settings.json`
  (тот же файл, что в ADR-010) под ключами `<псевдоним>[1m]` и `<псевдоним>` каждой модели
  шлюза. Ключ с `[1m]` нужен из-за ошибки Claude Code, без него — модели без `[1m]`.
- Пишется при старте PGC и при сохранении настроек и провайдера. Остальное в файле, порядок
  ключей и перевод строки в конце сохраняются; файл, который не читается или не объект,
  не трогаем.
- Значение убирается при пустом поле, только если оно равно тому, что PGC записал бы по прежнему
  значению поля. Выбор человека (`/autocompact` для обычной строки) и чужие ключи не трогаются.
- Изолированный запуск (`CLAUDE_GATEWAY_HOME`) файл не трогает.

## Consequences
- Поле действует и в Desktop, и в консоли; `/autocompact` в консоли PGC при заданном поле
  отвечает, что действует переменная.
- В `settings.json` человека появляются ключи модели шлюза с `autoCompactWindow`. Обычный
  `claude` без PGC этих моделей не знает и значений не использует.
- Процент считается от 1M (`[1m]`) или 200K, а не от каталога OpenCode: окно сессии Desktop
  PGC так и считает (ADR-011).
- Когда Claude Code исправит ключ с `[1m]`, запись под обычным ключом уже есть.
- Реальное срабатывание сжатия в Desktop на заданном пороге проверено только по ответу
  `/autocompact` («400k tokens (from settings)»).
