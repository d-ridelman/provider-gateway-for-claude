# ADR-006. VPN — внешнее ядро mihomo, качается по запросу

- Status: Accepted
- Date: 2026-11-23 (записано 2026-11-24)

## Context
Нужен VPN для Claude и провайдеров (подписки vless/vmess/ss/trojan/hysteria2), режимы
«только приложение», системный прокси и TUN. Ядро mihomo под GPL-3.0, PGC — MIT/Apache.

## Decision
mihomo — отдельный процесс (в job object; в TUN — повышенный, под надсмотрщиком), закреплённая версия, скачивается с релизов автора
по кнопке с проверкой sha256, в установщик не входит. TUN — через UAC и вспомогательный
экземпляр PGC. Упавшее ядро (кроме TUN) сторож поднимает до двух раз за 10 минут; запросы
при мёртвом ядре не идут в обход VPN.

## Consequences
- Лицензии не смешиваются; установщик маленький.
- Без сети до GitHub ядро не скачать; при смене версии — новая sha256 в коде.
