# ADR-014. Кнопка «Подключить проект»: agent-kit без ручных команд

- Status: Accepted
- Date: 2026-11-25

## Context
Чтобы подключить agent-kit к проекту, человек сейчас набирает команды `claude plugin …` в
нужной папке. Живая проверка 25.11 (настоящий проект из Claude, открытого через PGC) показала, где это
ломается:
- плагин поставили не в ту папку;
- проект работал со старой копией плагина;
- агенту пришлось прописывать путь к `agent-kit` руками;
- основная ветка проекта называлась не `main`.

Обычный пользователь PGC на этом бросит. У agent-kit есть машинные ответы: `inspect --json` и
план `setup`. Claude Code ставит плагины командой `claude plugin install … --scope
user|project|local --json` и сам добавляет маркетплейс через `--marketplace <источник>`.
`claude plugin list --json` отдаёт `installPath` и версию установленной копии.

## Decision
В PGC есть кнопка «Подключить проект». Она проходит шаги по порядку и после каждого
проверяет результат, ИИ не участвует:
1. **Предусловия.** Папка — git-репозиторий. Есть Claude Code CLI. Есть Node 22 или новее:
   код agent-kit на Node. Если чего-то нет, кнопка ничего не ставит и говорит, чего не
   хватает и что делать.
2. **Согласие.** Человек видит, что произойдёт, и нажимает «Подключить».
3. **Установка.** Плагин включается в области `local`: файл `.claude/settings.local.json`
   проекта, его нет в git. Область проекта (`project`, для всей команды) — только отдельным
   выбором. Источник маркетплейса берётся уже зарегистрированный, иначе из настройки PGC.
   Старая копия обновляется.
4. **Осмотр.** `inspect --json` установленной копии: что есть, чего нет, что сломано —
   простыми словами.
5. **План.** Список того, что `setup` создаст или допишет, с галочками. Существующие файлы
   не перезаписываются никогда.
6. **Применение** выбранного. Затем повторный осмотр: показать «было / стало» и список
   созданных файлов.

Каждый случай из таблицы ниже имеет ожидаемое поведение и тест. Тест полноты падает, если у
строки таблицы нет теста.

## Таблица случаев
| № | Случай | Что делает кнопка |
|---|---|---|
| 1 | Нет Node или Node старше 22 | ничего не ставит; говорит, какой нужен и где взять |
| 2 | Нет Claude Code CLI | ничего не ставит; предлагает скачать его в настройках PGC |
| 3 | Включён портативный Claude Code | ставит в его папку настроек (`CLAUDE_CONFIG_DIR`) |
| 4 | Папка — не git-репозиторий | ничего не ставит; так и говорит |
| 5 | Папка — подпапка репозитория (пакет монорепозитория) | подключает корень репозитория и называет его |
| 6 | Плагин уже включён (в любой области) | не ставит заново; сразу осмотр; старую копию называет осмотр |
| 7 | Плагин явно выключен в проекте (ближняя область решает) | говорит об этом; «Подключить» включает его (`claude plugin enable`), а не ставит заново |
| 8 | Ставится заново | после установки обновляет ту же область |
| 9 | Маркетплейс не зарегистрирован | ставит из источника PGC (его можно задать прямо на странице); нет источника — говорит |
| 10 | Критик не выбран | подключает; пишет, что критик пойдёт по подписке или не пойдёт |
| 11 | Критик совпадает с основной моделью | предупреждает |
| 12 | Путь с пробелами или кириллицей | работает так же |
| 13 | План `setup` пуст | так и говорит: «всё уже есть» |
| 14 | Команда упала или зависла | показывает её вывод; ничего не применяет дальше; таймаут |
| 15 | В рабочей копии незакоммиченные правки | предупреждает: заготовки лягут рядом, ничего не перезапишут |
| 16 | Нет git, или git отказал не потому, что это не репозиторий (чужой владелец папки) | говорит именно это, со словами git |
| 17 | Критик выбран, но шлюз остановлен или ещё не отдаёт эту модель | пишет: запустить или перезапустить шлюз и открыть Claude из PGC |
| 18 | Плагин только что включён | говорит, что он заработает в новых сессиях Claude |
| 19 | `claude` — это `claude.cmd` (npm) и завис | по таймауту снимается всё дерево процессов, не только cmd.exe |
| 20 | В этой сборке PGC agent-kit не встроен (сборка без снимка) | ставит из маркетплейса или источника, если они есть; иначе говорит об этом |
| 21 | Распакованная копия пропала или не та | распаковывает встроенную заново, через временную папку |
| 22 | Маркетплейс `agent-kit` зарегистрирован на другую папку | не трогает его и ставит из него |
| 23 | Маркетплейс не зарегистрирован, agent-kit встроен | регистрирует распакованную папку PGC |
| 24 | Встроенная версия отличается от установленной в проекте | говорит «другая версия»; ставит её только по кнопке |
| 25 | Проверки проекта (ADR-016): отобранные кодом и отсеянные правилом имён | первые с галочкой, вторые без неё и с причиной; модель не зовётся |
| 26 | Копия agent-kit не знает `--propose` или ответ непонятен | список проверок не показывается, остальное как раньше |
| 27 | Отмечена проверка, которой нет в отборе (окно отстало от диска) | отбрасывает её, передаёт только id из отбора |
| 28 | Отмечены проверки, а свой `.claude/verify.json` в проекте уже есть | файл не трогает; показывает шаги готовым текстом для ручного добавления |
| 29 | Отмечены проверки, а пункт «создать `.claude/verify.json`» снят | создаёт его всё равно: без файла отмеченным проверкам некуда попасть |
| 31 | agent-kit ставится из маркетплейса-папки человека, и её версия другая, чем у копии в проекте | говорит «другая версия»; ставит её только по кнопке; саму папку и маркетплейс не трогает |
| 32 | Claude Code не ответил на список плагинов или маркетплейсов (сбой, таймаут) | ничего не ставит и не включает: говорит проверить ещё раз |
| 30 | Черновик правил критика (`critic-md`, ADR-019 agent-kit) | без галочки, правила видны целиком; создаётся, только если человек отметил |

Node и git ищутся по свежему PATH из реестра Windows (и PATH самого PGC в конце): поставленные
после запуска PGC находятся без его перезапуска. Сам `claude` ищется так же, как для кнопки
«Claude Code»: если поставить его через npm уже при открытом PGC, может понадобиться перезапуск
PGC. Выключенный плагин включается только в области `local` этого проекта. Перед применением плана корень папки проверяется заново.
Если Node удалят после подключения, agent-kit ничего не блокирует: он предупреждает в начале
сессии, что нужен Node 22 (ADR-014 agent-kit).

## Consequences
- Подключение — кнопка и галочки, без команд и путей.
- В git проекта ничего не попадает, пока человек сам не выберет «для всей команды» или не
  закоммитит заготовки.
- PGC зависит от формата `inspect --json` и плана `setup`. Формат держит agent-kit, его тесты
  стоят на обеих сторонах.
- Откуда agent-kit берут другие люди (публичный маркетплейс или установщик PGC) — решение
  владельца. Источник в PGC — настройка, чтобы подходил любой ответ.
