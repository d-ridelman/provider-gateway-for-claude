# ADR-013. Проверки и критик PGC через agent-kit

- Status: Accepted
- Date: 2026-11-25

## Context
AGENTS.md требует считать работу готовой только после независимой проверки: свежий контекст
или другая модель. До сих пор агент делал её руками, запуская подагента. agent-kit, плагин
владельца, даёт три вещи:
- `agent-kit verify` — проверки только для изменённых файлов;
- `agent-kit critic` — критик в чистом контексте на другой модели. Через PGC это модель-критик
  из ADR-012;
- охранник, который не даёт агенту читать файлы секретов.

Репозиторий публичный. У других людей плагина нет, а его маркетплейс лежит в папке на машине
владельца. В PGC уже есть свои проверки: `tools/ci.ps1` гоняют хук `pre-push` и GitHub CI.
Журнал находок и цикл задачи живут в `notes/`, вне git. Ключ подписи обновлений лежит в
`%USERPROFILE%\.tauri`. Охранник пропускает `tools/ci.ps1` и `tools/release.ps1`, а прямое
чтение ключа блокирует (проверено подстановкой команд в `guard.mjs`).

## Decision
- `.claude/verify.json` повторяет шаги `tools/ci.ps1`: переводы, `cargo fmt`, clippy, тесты.
  Сборка и тесты идут не больше чем в два задания (`-j 2`). Для документов и заметок проверки
  не запускаются, для окна — только проверка переводов. Снимки окна (`tools/ui-shots.mjs
  --detect`, нужен плагин impeccable) остаются ручным шагом из AGENTS.md.
- `.claude/critic.md` говорит критику, где правила PGC и что для него важно.
- `.claude/settings.json` запрещает инструментам чтения файлов (Read, Grep, Glob) ключ подписи
  (`~/.tauri/**`) и его резервную копию (`handoff/**`) даже без плагина. Команды оболочки этот
  запрет не останавливает: их держит охранник плагина. Плагин включается только в
  `.claude/settings.local.json` у владельца, этот файл не в git.
- `pre-push` и GitHub CI остаются на `tools/ci.ps1`, второй хук не ставится. Шлюз изменений
  (`gates.json`) и `guard.json` не заводятся: шлюз слияния у PGC — человек, а секреты держит
  охранник плагина.
- Независимую проверку из AGENTS.md можно делать командой `agent-kit critic`, если плагин
  включён, и по-прежнему подагентом.

## Consequences
- Агент PGC гоняет только нужные проверки и получает критика без ручной настройки.
- Человек без agent-kit ничего не теряет: `tools/ci.ps1` и правила AGENTS.md прежние.
- Шаги в `verify.json` и `ci.ps1` нужно менять вместе.
