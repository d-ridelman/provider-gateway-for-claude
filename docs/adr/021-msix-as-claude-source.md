# ADR-021. Источник копии Claude — MSIX-пакет, когда Squirrel-папки нет

- Status: Accepted
- Date: 2026-11-26
- Supersedes: —

## Context

До 26.11.2026 официальный Claude на Windows ставился Squirrel-установщиком в
`%LOCALAPPDATA%\AnthropicClaude\app-X\`. PGC находил его там, собирал рядом русскую копию
(`ADR-002`) и патчил её (`ADR-018`).

Официальный установщик Anthropic (`claude.ai/api/desktop/…/setup/latest/redirect`) теперь
ставит **MSIX-пакет** (`Claude_pzs8sxrjxfjjc`) и удаляет Squirrel-папку: в
`%TEMP%\ClaudeSetup.log` — «Installing MSIX», «Launching Claude via explorer.exe
shell:AppsFolder\…», «No Squirrel installation found in %LOCALAPPDATA%, skipping uninstall».
Процессы в `%LOCALAPPDATA%\AnthropicClaude` больше нет, `claude::detect` его не находит.

Второй канал — портативные nupkg с `downloads.claude.ai/releases/win32/<версия>/` — пока
жив и даже свежее (7.37095.0 против 6.28899.6 в пакете). Но полагаться только на него
нельзя: если Anthropic его уберёт, PGC останется без источника и перестанет собирать
переведённую копию.

Проверено на машине владельца (26.11.2026):

- файлы пакета читаются обычным пользователем: `app.asar` (100 МБ) скопирован из
  `C:\Program Files\WindowsApps\Claude_…\app\resources\` за 0,2 с;
- `claude.exe` пакета, запущенный по пути (без идентичности пакета) с отдельным
  `--user-data-dir`, живёт и плодит дочерние процессы — то есть копия из пакета запустится;
- корень пакета без PowerShell отдаёт реестр:
  `HKCU\Software\Classes\Local Settings\…\AppModel\Repository\Packages\<PackageFullName>`,
  значение `PackageRootFolder` (перечисление всех пакетов — 33 мс; `Get-AppxPackage` — 1,3 с).

Имя пакета — `Claude_<версия>_x64__<family>`, внутри — та же раскладка `app\claude.exe`,
`app\resources\app.asar`, `app\resources\ion-dist.asar`, что у Squirrel и у портативного.

## Decision

1. `claude::detect` добавляет последним запасным вариантом `claude.exe` из MSIX-пакета
   текущего пользователя. Порядок прежний: явный `claudePath` → Squirrel `app-X` →
   заглушка/`Programs\claude` → MSIX. Версии не сравниваются: явный путь и Squirrel
   остаются приоритетнее, чтобы уже настроенный портативный Claude не перебивался старым
   пакетом.
2. Пакет ищется по реестру `AppModel\Repository\Packages`, без PowerShell: `detect`
   зовётся часто (`upkeep`, настройки, запуск), а `Get-AppxPackage` стоит 1,3 с.
   Берётся пакет с самой старшей версией, у которого есть `app\claude.exe`.
3. Папка версии копии для пакета называется `app-<версия>` (как у Squirrel): версия
   берётся из имени пакета. У пакета версия четырёхсоставная (`6.28899.6.0`), у nupkg —
   трёхсоставная (`7.37095.0`), поэтому папки обычно разные; совпадение имён не опасно —
   метка копии хранит отпечатки и пересоберёт её.
4. `upkeep::app_dir` и ремонт реестра (`repair_for`) считают папкой версии и
   `<package>\app`: иначе проверки не работали бы, а `claude://` после запуска копии
   остался бы указывать на неё.

## Consequences

- Когда nupkg-фид исчезнет, PGC продолжит собирать переведённую копию — теперь из пакета.
  Сегодня он работает как раньше: явный `claudePath` на портативный 7.37095.0 приоритетнее.
- Копия из пакета наследует версию пакета. Обновился пакет — при следующем запуске копия
  пересоберётся (метка копии). Обновление пакета при открытой копии Windows не даст
  заменить — PGC скажет закрыть Claude, как и раньше.
- Пакет можно удалить (Store, `Remove-AppxPackage`) — PGC вернётся к портативному/явному
  пути. Откат безопасен: ни пакет, ни его профиль PGC не меняет.
- Копия из пакета — обычный `claude.exe` без идентичности пакета: VM-режим (`ADR-018`) она
  не включает, служба `CoworkVMService` её не примет. Для VM по-прежнему запускается
  настоящий exe пакета.
- Не делаем: запуск пакета через `shell:AppsFolder`, сравнение версий пакета и nupkg,
  автообновление пакета, сборку из скачанного `.msix` (а не установленного).

## Проверки

- `copy_marker`: версия из имени пакета (`Claude_6.28899.6.0_x64__…` → `app-6.28899.6.0`),
  и прежнее поведение для `app-…`; переименованный пакет (`Claude_old\app`) отвергается.
- `msix::package_version` — табличный тест на имена пакетов и мусор (работает и на CI).
- `msix::installed_exe` на живом реестре: с установленным пакетом проверяет найденный путь,
  без пакета (CI) ничего не делает.
- Живая сборка: копия из настоящего пакета 6.28899.6 собрана и пропатчена за 25 с
  (`#[ignore]`-тест `a_copy_from_the_msix_package_is_built_and_patched`). Запуск этой
  копии не проверен: exe пакета отдельно проверен (10 с с временным профилем).
