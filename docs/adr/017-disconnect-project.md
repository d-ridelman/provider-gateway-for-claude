# ADR-017. Одна страница «Проекты»: подключить, посмотреть, отключить

- Status: Accepted
- Date: 2026-11-25

## Context
«Подключить проект» (ADR-014) включает agent-kit и раскладывает его файлы, но обратного пути не
было: выключить плагин и убрать файлы можно было только руками. Отдельная кнопка «Отключить» в
боковой панели плодила бы кнопки. Человеку нужен один вход: что с этим проектом и что с ним
сделать.

## Decision
1. **Одна кнопка «Проекты»** в боковой панели вместо «Подключить проект». Страница проверяет
   папку и предлагает то, что к ней подходит:
   - не подключён — «Подключить» (как в ADR-014);
   - подключён — «Открыть осмотр» и «Отключить…».

   В осмотре и в плане отключения есть «Назад» к выбору папки.
2. **Отключение — план с галочками, как подключение.** Ничего не меняется до «Отключить
   отмеченное». План собирает agent-kit (`setup --undo --json`):
   - созданный kit-ом файл, который человек не правил, — убрать;
   - файл, который правили после, — оставить, без галочки, с причиной;
   - дописанные kit-ом строки в `.gitignore` и `.claude/settings.json` — убрать, только если они ещё
     на месте; чужие строки рядом не трогаются.

   agent-kit узнаёт своё по журналу применения (`.git/agent-kit/applied.jsonl`, вне дерева и git), а
   без журнала — по побайтному совпадению с заготовкой своей версии.
3. **Плагин PGC выключает сам**, отдельным пунктом:
   - «Выключить agent-kit в этом проекте» — с галочкой, `claude plugin disable --scope local`:
     только у человека, git проекта не меняется;
   - если плагин включён «для всей команды» (область `project`), пункт «Выключить для всей команды
     (в git проекта)» — без галочки: это меняет общий файл.
4. **Ничего необратимого.** Удаляется только нетронутая заготовка, которую можно создать заново
   подключением; то, что было в git, возвращает git. Правки человека не трогаются никогда.

Новые случаи — строки таблицы ADR-014 с тестами.

## Consequences
- Подключение можно отменить из того же окна, без команд.
- PGC зависит от формата `setup --undo --json`, как и от `setup --json` (тесты на обеих сторонах).
- Старая копия agent-kit без `--undo` даёт только пункт про плагин; файлы тогда убираются руками,
  и страница говорит об этом.
