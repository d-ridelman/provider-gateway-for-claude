# ADR-004. Одна основная модель для Claude Code

- Status: Accepted
- Date: 2026-11-24
- Изменено: ADR-010 (PGC правит ключ `model` в `settings.json` Claude Code), ADR-012 (вторая
  модель — критик для скриптов проекта)
- Supersedes: роли сильная/быстрая и советник шлюза (0.2.0–0.2.1, решения до журнала)

## Context
Роли `opus`/`haiku` и советник (`/advisor` на сильной модели) путали: агенты пользователя
с `model: opus` уходили не туда, советник писал в общий `~/.claude/settings.json`, а
`/model` показывал Opus и Fable Anthropic с ценами, недоступные через шлюз.

## Decision
В настройках одна основная модель. Все роли Claude Code (`sonnet`, `opus`, `haiku`, `fable`)
идут на неё и подписаны её именем (`ANTHROPIC_DEFAULT_*_MODEL_NAME`/`_DESCRIPTION`).
Советника шлюз не исполняет: объявление и его блоки в истории выбрасываются у всех
провайдеров. PGC не пишет в настройки Claude Code.

## Consequences
- `/model` честный: четыре строки одной модели и «Default».
- Нельзя дать субагентам другую модель из окна; можно — полем `model:` агента или `/model`.
