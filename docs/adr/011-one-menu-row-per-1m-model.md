# ADR-011. Одна строка в меню Claude на модель с окном 1M

- Status: Accepted
- Date: 2026-11-25

## Context
Модели с `[1m]` PGC пишет в `inferenceModels` с `supports1m: true`. Claude Desktop тогда
показывает две строки: обычную, где Claude считает окно 200K, и «… 1 млн» с подписью
«1M context window». Подпись зашита в главный процесс Claude, а не в файлы перевода.
У провайдера за обеими строками одна и та же модель: шлюз отрезает `[1m]` и шлёт тот же ID.
Строки отличаются только окном, на которое рассчитывает Claude, то есть тем, когда он
начнёт сжимать разговор. Людей вторая строка путает.

Исключение — настоящая модель Claude у Anthropic. Там вариант 1M включается заголовком
`context-1m-…`, и шлюз передаёт его как есть. Запросы длиннее 200K стоят дороже, так что
выбор между строками настоящий. (Неверно для Claude 5.x, см. исправление от 25.11 ниже.)

В схеме `inferenceModels` Claude (с 1.21459.0, проверено на 6.28899.6) есть ключ
`prefer1m` («Only show the 1M option»). С ним Claude показывает одну строку, а сессии
берут `<id>[1m]`. Окна, кроме 200K и 1M, Desktop не показывает. Настоящее окно консоли
PGC передаёт отдельно через `CLAUDE_CODE_MAX_CONTEXT_TOKENS`, как Ollama.

## Decision
PGC пишет `prefer1m: true` всем моделям с `[1m]`, кроме моделей Claude у
Anthropic-совместимого провайдера: не через OpenAI-путь, и в ID есть `claude-` в любом
регистре, в том числе под чужим ID агрегатора (`anthropic/claude-…`, `us.anthropic.claude-…`).
Самопроверка Claude знает ключ `prefer1m`: если Claude перестанет его понимать, это будет видно.

Дополнение от 25.11: модель не-Claude без `[1m]` и без уровней рассуждения тоже получает
`supports1m` и `prefer1m`. У неё нет образца `behavesAs`, который дал бы окно 1M, и без этого
Desktop считал бы своё окно 200K. Так правило ADR-005 «неизвестное окно — 1M» действует для
всех моделей, а не только для моделей с уровнями.

Исправление от 25.11: исключение для Claude у Anthropic снято, одна строка у всех моделей с
окном 1M. Довод о другой цене неверен для нынешних моделей. Источник: каталог моделей
Anthropic в справочнике Claude API Claude Code 2.1.330 (снимок от 03.11.2026), свежие данные —
Models API (`max_input_tokens`). По нему у Sonnet 5.5, Opus 5.5 и Haiku 5.5 окно 1M своё, без
заголовка. У Sonnet 5.5 ($2/$10) и Opus 5.5 ($4/$20) указана одна цена, без надбавки за длинный
запрос. У Haiku 5.5 цена выше после 100K ($0.10/$0.50 до, $0.50/$2.50 после), и от строки меню
это не зависит. Вживую: сессия Sonnet 5.5 на «обычной» строке прошла 232K токенов без сжатия, и
Claude показывал окно «из 1 млн». Обе строки вели себя одинаково.

## Consequences
- У сторонних моделей одна строка, без английской подписи. Сессии вкладки Code сразу
  получают окно 1M.
- У Claude от Anthropic тоже одна строка (после исправления от 25.11). Модель Claude без
  `[1m]` остаётся одной строкой со своим окном.
- Вариант «200K» у сторонней модели с `[1m]` пропадает. Кому он нужен, убирает `[1m]` у
  модели.
- Сессии сторонней модели с `[1m]` всегда идут как `<id>[1m]`. Если Anthropic-совместимый
  провайдер не-Claude отвергает бета-заголовок `context-1m-…` (если Claude его шлёт), раньше
  можно было уйти на строку 200K, теперь — убрать `[1m]` у модели. Не проверено.
- Меню проверено только по коду Claude. Вживую нужно проверить после установки.
