# ADR-009. Перевод меню усилий собирается под каждую версию Claude

- Status: Accepted
- Date: 2026-11-24

## Context
Подписи из каталога моделей (уровни усилий, их описание, режимы размышлений) Claude берёт не
из `i18n/<язык>.json`, а из второго файла, `i18n/dynamic/<язык>.json` (ключ → текст). В
Claude 6.28899 там 51 строка. Первая версия исправления (до этого ADR) клала в архив вшитый `ru-catalog.json`,
составленный под эту версию. Если Claude обновится и добавит или изменит строки, вшитый
словарь устареет: новые строки останутся английскими, пока не выйдет новая версия PGC.

У claude.ai есть официальный `https://claude.ai/i18n/dynamic/ru.json`: 51 строка, тот же
формат. Он закрыт той же проверкой Cloudflare, что и `/i18n/ru.json`, а её PGC уже умеет
проходить (`upkeep::download_translation`). Ещё 16 из 51 строк дословно совпадают по
английскому тексту со строками основного `en-US.json`, у которых есть русский перевод.

## Decision
Вместе с основным переводом PGC скачивает и официальный `dynamic/ru.json`
(`claude-ru-dynamic.json` в папке настроек). Это попытка без гарантий: неудача не мешает ни
основному переводу, ни сборке копии, а повтор идёт не чаще паузы по версии Claude. При
сборке копии `i18n/dynamic/ru.json` составляется заново из ключей
`i18n/dynamic/en-US.json` этой версии Claude. Для каждого ключа источники перебираются по
порядку, берётся первый, где строка есть:
1. скачанный официальный файл, по ключу;
2. вшитый `ru-catalog.json`, по ключу;
3. основной перевод: строка `en-US.json` с тем же английским текстом, её русский вариант.

Сначала идут источники по ключу: короткие строки вроде «High» по тексту могут совпасть с
чужими. Ключ, которого нет ни в одном источнике, не пишется, и Claude покажет его
по-английски. Если в версии Claude нет `dynamic/en-US.json`, пишется официальный файл
поверх вшитого, как раньше. Хеш скачанного файла входит в метку копии: когда он появляется
или меняется, копия пересобирается, а открытая копия ждёт закрытия, как при смене основного
перевода.

## Consequences
- После обновления Claude меню переводится без новой версии PGC, как только claude.ai
  выложил перевод. До этого выручают вшитый словарь и совпадения по тексту.
- Лишних строк, которых нет в этой версии Claude, в копии не остаётся.
- Копия может пересобраться лишний раз (~700 МБ), когда официальный файл приходит позже
  основного перевода. Это в фоне и раз на версию.
- Самопроверка показывает, сколько строк меню переведено, в строке «Перевод».
